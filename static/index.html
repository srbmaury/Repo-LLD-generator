Repository LLD Generator

Depth decides how the code is split into diagrams. The generator finds the folder that all .java files share, goes down that many folder levels, and draws one diagram per folder there.

Example, under com/conceptcoding/: 1 → one diagram per category (behavioralpatterns) · 2 → one per example (behavioralpatterns/observer) · 3 → one per layer inside an example (book_my_show/service), losing links between layers.

Use 2 for repos of independent examples, 1 or Single diagram for one application. Depth is ignored when the repo has Maven/Gradle modules (one diagram per module) or Single diagram is checked.
